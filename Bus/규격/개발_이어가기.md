- `python-pptx`는 pip로 설치 가능(3.9.6 환경에서도 동작). `validate.py`/`soffice.py` 같은 pptx 스킬의 검증 도구는 Python 3.10+ 문법을 써서 이 환경에서 `SyntaxError`로 실패함 — pptx를 직접 다뤄야 하면 `python-pptx`로 위치 매칭(`Emu(shape.top).inches` 등) 후 `run.text`만 고치는 방식으로 우회.

### 아트 적용·배포하며 배운 것 (2026-10)
