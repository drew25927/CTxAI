11/10 검토 반영: 제출판은 포스터 배경판(render/제출/), 글 장 12~16초로 늘림, 장에도 빗소리·BGM 을 작게 깔음, 장르 이름·세 화면 문구에 어두운 띠, 끝 타이틀 뺌, 영문 뒤 조사 붙여 씀, 자막 두 줄 표기 수정. 2차: 한국어 낱말 단위 줄바꿈(keep-all), 글 장 더 길게, 영상 자리 장 「풀 영상」, 「고개 젓기」·「블랙코미디」로 통일, 파일 이름 NFC(Windows 에서 자모 풀림 방지).

11/11 시험판(`render/시험/*_시험.mp4`, 제출본과 별개): 데모 시네마틱(`BUS_STOP_DEMO_4CLIPS_1080_20261110_R01`) 두 컷을 섞음 — 본영상 앞에 01의 VR 관객 컷(0.9~4.85초, 빗소리 깔음), 몽타주 고양이를 04(0.2~4.6초)로 교체, 트럭·고양이 문구에 어두운 띠. 1080p 를 4K 로 늘림. 길이: 메인 85.7초 · 서브 175.7초 · 심포지엄 146.7초. 만들기: `DEMO=<데모 폴더> python3 make_plans.py …`.

11/11 데모 소스판(`render/데모소스/*_데모소스.mp4`, 제출본과 별개): 본영상 화면을 데모 시네마틱(4클립 + `BUS_STOP_COMEDY_R03_1080_DELIVERY`)으로만 짬 — 「같은 정류장」 → VR 관객 → 벤치 정면 → 카페 인물이 횡단보도를 건넘 → 「당신의 감정을 예측해, 이야기의 흐름이 바뀐다.」(장르가 하나뿐이라 「당신이 정한다」 대신) → 인물이 걸어오며 블랙코미디 할머니로 변해 옆에 앉음(25초) → 트럭 → 고양이 → 빈 인도 → 끝 문구. 무음 컷엔 녹화본 빗소리·BGM 만 깔음. 길이: 메인 95.0초 · 서브 145.0초 · 심포지엄 116.0초. 만들기: `DEMO=… DEMO_COMEDY=… DEMO_ONLY=1 python3 make_plans.py …`. (edit.swift: 세 화면 비교가 없는 판에서 빈 보조 트랙 때문에 "Source frame missing" 으로 멈추던 것 고침)

본영상은 훅 구조다(체험 순서를 따라가면 빈 도로·걸어 들어오는 컷아웃·긴 침묵이 드러나서):
「같은 정류장. 같은 5분.」 → 세 인물의 센 한 마디(공포·블랙코미디·로맨스) → 「옆에 앉는 사람은, 당신이 정한다.」
→ 트럭·고양이(무엇에 놀라는지 / 무엇을 바라보는지) → 세 화면 비교 「같은 순간, 세 개의 영화」(말하는 칸만 밝게)
→ 장르별 예고편(줄 세 개씩) → 버스와 마지막 말 → 「버스는 누구에게나 온다. 다만 나의 기다림, 그건 나만의 경험이다.」 → 타이틀.
1분 축약은 몽타주를 빼고 예고편을 장르당 한 줄로 줄인 판.

- 전부 3840×2160 · H.264 · AAC. 대사 자막과 장르 이름(로맨스·공포·블랙코미디)을 화면에 새겼다
- 원본: `ctxai-busstop-xr-audio-proto/capture/v2_{R,H,C}.mp4` + 대사 시각 `v2_*.json` (녹화 중 기록)
- 다시 만들기: `python3 make_slides.py <배경폴더> <slides>` → `snap`(snap.swift) 로 장 PNG → `python3 make_plans.py <capture> <slides> <plans>` → `swift edit.swift plans/<이름>.json <출력.mp4>`
- 타이포는 포스터를 따른다: 크림색, 제목·장르명 함렛 Black, 소개글·자막 본명조 Light (fonts/, OFL)
- 장 문구는 디렉토리북 원고(팀 확정본)에서 가져왔다. 크레딧은 이름만 — 직책은 비워 둠
